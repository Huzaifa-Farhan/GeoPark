# GeoPark identity kit

Start with `GeoPark-Brand-Guidelines.md`. Use the supplied SVG wordmarks rather than retyping the logo.

Import `geopark-theme.css` into your app and map its semantic variables to your existing Tailwind theme or CSS component styles. `geopark-tokens.json` contains the complete design decisions. Set `data-theme="dark"` on a container to use the alternate tokens.

Load DM Sans with `@font-face`, the four files in `fonts/`, and `font-display: swap`. Retain the included Open Font License when redistributing font files. The logo files use outlined lettering and need no font installation.

Brand expression: “A little less circling.”
Palette: #174BE8, #172D28, #F5F6F2, #DFEFB7, #D9DFD6.

The social cover is an SVG vector master at 1200 × 630. Export a PNG from a vector editor when required by a social platform.
